# Day 2 — Dictionary, Boolean and Set

Today I continued working on my Python fundamentals. I went a little deeper into three basic concepts: **Dictionaries, Booleans, and Sets**.

## What I Learned

### 1. Dictionary

I learned that a dictionary stores data in **key-value pairs**.

```python
student = {
    "name": "Darshan",
    "age": 20,
    "branch": "AI/ML"
}

print(student["name"])
```

I also learned that dictionaries are useful when I want to store related information and access it using a specific key.

### 2. Boolean

I learned about the Boolean data type, which has only two possible values:

```python
True
False
```

Booleans are mainly used when working with conditions and checking whether something is true or false.

```python
age = 20

print(age >= 18)
```

The output will be:

```text
True
```

This is important because conditions and decision-making are used throughout Python programs and will also be important when I start working with Machine Learning logic.

### 3. Set

I learned more about sets and how they are used to store **unique values**.

```python
numbers = {1, 2, 3, 3, 4}

print(numbers)
```

The duplicate value is automatically removed.

I also learned that sets are useful when I don't want duplicate values in my data.

## What I Understood Today

Today I got a better understanding of how dictionaries, Booleans, and sets work in Python.

* **Dictionary** → stores data as key-value pairs
* **Boolean** → represents `True` or `False`
* **Set** → stores unique values

These may look like simple concepts, but I know I'll be using them regularly while writing Python programs and eventually working with AI/ML.
